One line of software error copy that tells the user the brutal truth about
what went wrong — and makes them laugh on the way.

> The server is down because someone deployed on a Friday. We found the
> someone. It was us. Try again in ten minutes.

`main.ts` writes the line to `/output/entry.txt` (115 characters, one line).
